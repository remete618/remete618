I build memory and data tooling for LLM agents and robotics. Local-first by default.

- [widemem-ai](https://github.com/remete618/widemem-ai): local-first memory layer for LLM agents. Runs offline on Ollama, MCP server included.
- [mcap-encrypt](https://github.com/remete618/mcap-encrypt): public-key encryption for MCAP robotics logs. Go, TypeScript, Python.
- [llm-txt-gen](https://github.com/remete618/llm-txt-gen): CLI that generates /llms.txt for any site.

Product and GTM at [Foxglove](https://foxglove.dev) by day.

More on the memory work at [widemem.ai](https://widemem.ai).
